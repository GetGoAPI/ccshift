常见问题

需要提前安装 Node.js、Git 吗？

不需要。打开 ccshift 后点「一键全部安装」，缺什么会自动装什么。已经装过的会自动识别，不会重复安装；Node.js 版本太旧会提示一键升级。

需要管理员权限吗？

一般不需要，所有东西都装在你的用户目录里。只有一种情况例外：电脑上原来装了旧版 Node.js（装在系统目录），升级时 Windows 会弹一次"是否允许更改"，点「是」即可。

配置完了，但 Claude Code / Codex 还是用的旧配置？

已经打开的终端、VS Code、Cursor 读不到新配置，请把它们完全关掉再重新打开。

如果还不行，回到 ccshift 的「快速配置」看看有没有红色的「环境变量冲突」，点「一键清除」即可（原值会自动备份）。

支持 Claude 桌面版和 Codex 桌面版吗？

支持。Claude 桌面版在「快速配置」里勾选即可，配置后会自动重启生效，不用在桌面版里做任何设置（仅支持 Anthropic 格式的接口）。

Codex 桌面版和命令行版读的是同一份配置，配好 Codex 就自动生效。

VS Code / Cursor 里的插件能用吗？

能。Claude Code 插件和 Codex 插件读的就是 ccshift 写入的配置。插件需要你自己在扩展市场里安装，配置或切换后重启编辑器即可。插件弹出登录提示时不用登录。

不想用了怎么恢复？

在 ccshift 的「设置 → 通用 → 一键还原」里可以选择：

· 只还原配置：Claude Code、Codex 恢复成使用 ccshift 之前的样子。
· 彻底清理：再卸载 Claude Code、Codex，并删除 ccshift 安装的 Node.js 和 Git。你自己原来装的不会被删除。

建议先还原，再卸载 ccshift。

我的 API Key 安全吗？

Key 只保存在你自己的电脑上，写进 Claude Code 和 Codex 的本地配置文件，ccshift 不会上传到任何服务器。
